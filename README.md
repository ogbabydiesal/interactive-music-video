# About
An audio-responsive "music video" inspired by MGMT's Electric Feel "interactive video game project" from 2007 (directed by Ray Tintori and Jordan Fish). https://www.youtube.com/watch?v=0KT4xnysMBE 

The QuickTime downloadable file allowed fans to interact with the music video by clicking buttons to change video compositing modes. 

This web-based version demonstrates how to layer videos with the `mix-blend-mode` css attribute. It also demonstrates how to change properties like opacity with the music's amplitude (loudness).
# Setup
1. Place audio and video files in the ```/media``` folder.
2. call them ```video1.mp4```, ```video2.mp4``` and the audio file should be called ```music.mp3```.
